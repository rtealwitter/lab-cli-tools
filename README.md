# lab-cli-tools

Recover a practice archive and report its status with the installed Cowsay command.
The supplied `recovery_status.py` connects the display and recovered file as ungraded practice.
Setup, requirements, and submission instructions are on the [weekly lab](https://csci40.rtealwitter.com/topics/04_exceptions/lab.html).

Adapted from Mike Izbicki's [Cowsay](https://github.com/mikeizbicki/lab-cowsay) and [password-cracking](https://github.com/mikeizbicki/lab-password-cracking) labs.
